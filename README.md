# sakiya
sakiya discord bot

to use: run bot.py

## features:

chat

1. @sakiya message/question/whatever
2. /sakiya message/question/whatever
3. dm sakiya 

/sync_memory 

- absorbs the last 25 messages of the chat into memory (max 25 messages memory)

/clear_memory

- clears only the bot's memory of you
